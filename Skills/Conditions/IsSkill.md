## 描述
检查指定的元技能是否存在。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| name | n, skill, s | 要检查存在性的元技能 |  |



## 示例
```yaml
  Conditions:
  - isSkill{skill=ExampleMetaSkill}
```


## 别名
- [x] skillexists
