## 描述
检查目标实体的大小。  
有效的实体：`史莱姆`、`岩浆怪`、`幻翼`


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| size      | s         | 要检查的大小                                                |         |


## 示例
```yaml
  TargetConditions:
  - size{s=>1} true
```


## 别名
- [x] mobSize
