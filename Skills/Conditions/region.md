## 描述
检测目标是否在指定的 WorldGuard 区域内。

> 通过 `/rg create` 命令创建区域时，名称*始终*会变成小写，无论你在命令中输入什么。因此，当你需要用此条件检测此类区域时，记得也用小写书写其名称。

## 属性

| 属性       | 别名        | 描述       | 默认值 |
| ---------- | ----------- | ---------- | ------ |
| region     | r, name, n  | 要检测的区域 |        |


## 示例
```yaml
  Conditions:
  - region{r=someregion} true
```

## 别名
- [x] inregion
