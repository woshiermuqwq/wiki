## 描述
检查目标是否在给定的 WorldGuard 区域内。

> 当通过 `/rg create` 指令创建区域时，名称将*始终*为小写，无论你在指令中输入了什么。因此，当需要通过此条件检查这类区域时，请记住也用小写书写区域名称。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| region    | r, name, n| 要检查的区域                                                  |         |


## 示例
```yaml
  Conditions:
  - region{r=someregion} true
```


## 别名
- [x] inregion
