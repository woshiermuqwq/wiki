## 描述
检查目标的 Y 坐标是否高于某个值。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| height    | h         | 目标必须高于的高度                                        |         |


## 示例
```yaml
  Conditions:
  - heightabove{h=50} true
```
