## 描述
检查目标实体与施法者之间的 X 坐标差值。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| difference| diff, d   | 要检查的 X 坐标差值                                            |         |


## 示例
```yaml
  TargetConditions:
  - xDiff{diff=>5} true
```
