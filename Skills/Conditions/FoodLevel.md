## 描述
检查目标的饥饿值。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| amount    | a, food, f| 要检查的饥饿值范围                                 | 0       |


## 示例
```yaml
  TargetConditions:
  - FoodLevel{a=<10} true
```


## 别名
- [x] hunger
- [x] food
- [x] hungerlevel
