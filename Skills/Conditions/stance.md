## 描述
检测目标生物的当前姿态。

## 属性

| 属性       | 别名   | 描述                                                     | 默认值   |
| ---------- | ------ | -------------------------------------------------------- | -------- |
| stance     | s      | 要匹配的姿态                                              | DEFAULT  |
| strict     | str    | 是否精确匹配。设为 false 时只检查当前姿态是否包含该关键字  | true     |


## 示例
```yaml
  Conditions:
  - stance{s=CombatStance;str=true} true
```
