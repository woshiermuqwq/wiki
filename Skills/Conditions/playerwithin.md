## 描述
检查目标半径范围内是否有玩家。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| distance  | d         | 要检查的半径                                               | 0       |


## 示例
```yaml
  Conditions:
  - playerwithin{d=10} true
```


## 别名
- [x] playerswithin
