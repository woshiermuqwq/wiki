## 描述
检查可以改变大小的实体（史莱姆、岩浆怪和幻翼）的大小。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| size      | s         | 要检查的大小范围                                              |         |


## 示例
```yaml
- size{s=>5} true
```


## 别名
- [x] size
