## 描述
检查目标实体 Y 轴运动量是否在范围内。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| velocity  | v         | 要检查的速度向量                                            |         |


## 示例
```yaml
  Conditions:
  - motiony{v=<1} true
```


## 别名
- [x] moty
