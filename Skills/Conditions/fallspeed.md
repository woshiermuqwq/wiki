## 描述
检查目标的坠落速度是否在给定范围内。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| speed     | s         | 要匹配的速度向量                                                |         |


## 示例

```yaml
  Conditions:
  - fallspeed{s=>5} true
```


## 别名
- [x] fallingspeed
