## 描述
检查当前的月相。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| phases    | p, phase  | 要检查的月相。可以是列表。              | 0<!--type:0,1,2,3,4,5,6,7--><!--list-->|

### Phase 属性
请注意，你**必须**使用月相编号。下表帮助你匹配月相名称和编号。

| 月相名称    | 月相编号 |
| --------------- | -------------|
| 满月       |       0      |
| 亏凸月  |       1      |
| 下弦月   |       2      |
| 亏蛾眉月 |       3      |
| 新月        |       4      |
| 盈蛾眉月 |       5      |
| 上弦月   |       6      |
| 盈凸月  |       7      |


## 示例
```yaml
  Conditions:
  - lunarphase{p=0} true
```
```yaml
  Conditions:
  - lunarphase{p=0,2,4,6} true
```
