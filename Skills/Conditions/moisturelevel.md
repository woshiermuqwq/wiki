## 描述
检查目标耕地方块是否具有指定湿润等级。

- `0` 表示耕地未被湿润
- `1-6` 表示曾经被湿润的耕地在失去水源后逐渐失去湿润度
- `7` 表示完全湿润的耕地。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| l         | moistness, m | 要检查的湿润等级                             |         |


## 示例
```yml
  TargetConditions:
  - moisturelevel{l=3} true
```
```yml
  TargetConditions:
  - moistureness{l=1to6} true
```

## 别名
- [x] moistureness
