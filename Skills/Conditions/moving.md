## 描述
检查目标的速度向量是否大于零。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| exact     | e         | 检查是否应精确还是近似                         | true    |


## 示例
```yaml
  Conditions:
  - moving true
```


## 别名
- [x] ismoving
