## 描述
检查目标实体的俯仰角是否在范围内。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| pitch     | p         | 要匹配的数值范围                                            |         |



## 示例
```yaml
  Conditions:
  - pitch{p=-45to45} true
```

```yaml
  Conditions:
  - pitch{p=>45} true
```
