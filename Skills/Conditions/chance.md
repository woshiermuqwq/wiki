## 描述
设置元技能被执行的概率。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| chance    | c         | 表示概率的浮点值。范围在 0 到 1 之间，0 表示 0% 概率，1 表示 100% 概率                                                  |   0.5   |

## 示例
在此示例中，元技能平均只会在被触发次数的 30% 时被执行。
```yaml
Conditions:
  - chance{chance=0.3} true
```

而在另一个示例中，元技能反而会在 70% 的触发次数中被执行。
```yaml
Conditions:
  - chance{chance=0.3} false
```
