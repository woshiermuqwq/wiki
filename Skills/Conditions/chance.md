## 描述
设置技能执行的随机概率。

## 属性

| 属性      | 别名   | 描述                                                          | 默认值 |
| --------- | ------ | ------------------------------------------------------------- | ------ |
| chance    | c      | 表示概率的浮点值，范围在 0 到 1 之间，0 表示 0% 概率，1 表示 100% 概率 | 0.5    |

## 示例
在此示例中，技能平均只有 30% 的触发次数会真正执行。
```yaml
Conditions:
  - chance{chance=0.3} true
```

在此示例中，技能将有 70% 的触发次数会执行（取反逻辑）。
```yaml
Conditions:
  - chance{chance=0.3} false
```
