## 描述
检查目标的 Y 坐标是否在范围内。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| height    | h         | 目标的 Y 坐标范围                            |         |


## 示例
```yaml
  Conditions:
  - height{h=<50} true
```
