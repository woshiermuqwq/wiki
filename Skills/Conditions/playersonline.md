## 描述
匹配服务器在线玩家的数量。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| amount    | a         | 要检查的玩家数量。可以是范围                   | 0       |


## 示例
```yaml
  Conditions:
  - playersOnline{amount=>5}
```


## 别名
- [x] onlineplayercount
- [x] onlineplayers
