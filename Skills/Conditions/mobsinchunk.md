## 描述
匹配目标位置所在区块中的生物数量范围。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| amount    | a         | 要匹配的数量范围                                            | 0       |


## 示例
```yaml
  Conditions:
  - mobsinchunk{a=1to5} true
```

```yaml
  Conditions:
  - mobsinchunk{a=<5} true
```
