## 描述
检查服务器是否运行特定的 Minecraft 版本。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| version   | sv, v       | 要检查的版本                                           | 1.19.3  |


## 示例
```yaml
  Conditions:
  - serverversion{v="v1.19.4"} true
```


## 别名
- [x] server
- [x] version
