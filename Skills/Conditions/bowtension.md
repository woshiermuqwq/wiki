## 描述
检测生物射箭时的弓弦张力。

## 属性

| 属性      | 别名                | 描述                                                          | 默认值 |
| --------- | ------------------- | ------------------------------------------------------------- | ------ |
| force     | f, value, v, val    | 要检测的力度/张力值。接受范围浮点值，但仅限于 0 到 1 之间       | >0     |


## 示例

```yaml
  Conditions:
  - bowtension{value=>0.5} true
```
