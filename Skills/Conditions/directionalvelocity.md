## 描述
检测目标的速度是否与给定参数匹配。

## 属性
| 属性       | 别名                    | 描述                                                            | 默认值            |
| ---------- | ----------------------- | --------------------------------------------------------------- | ----------------- |
| x          | s, side                 | X 轴速度。可为范围值。不设置则此项不检测                          |                   |
| absx       | ax, abss, as            | X 轴速度是否只使用绝对值                                          | `relative` 的值   |
| y          | up, down, vertical, v   | Y 轴速度。可为范围值。不设置则此项不检测                          |                   |
| absy       | ay                      | Y 轴速度是否只使用绝对值                                          | false             |
| z          | f, forward              | Z 轴速度。可为范围值。不设置则此项不检测                          |                   |
| absz       | az, absf, af            | Z 轴速度是否只使用绝对值                                          | false             |
| relative   | rel                     | 是否相对于生物朝向而非世界坐标轴。启用后 X 为前后，Z 为左右       | false             |

### X、Y、Z 属性
它们检测生物沿各轴的速度。这意味着速度本身会根据方向有正有负。
> - 向 **X 轴正方向**移动时，X 速度为**正值**。
> - 向 **X 轴负方向**移动时，X 速度为**负值**。
> - **向上跳跃**时，Y 速度为**正值**。
> - **向下坠落**时，Y 速度为**负值**。

### Absx、Absy、Absz 属性
也许你不想检测运动的*方向*，而是其*大小*。为此需要启用这些属性，启用后对应的 X、Y 或 Z 属性将只检测绝对值（无论实际方向如何，始终为正）。
> - **向上跳跃**时，Y 速度视为**正值**。
> - **向下坠落**时，Y 速度视为**正值**。

## 示例
在此示例中，检测玩家的 Y 轴速度的绝对值是否小于 5。
```yaml
  Conditions:
  - directionalVelocity{y=<0;absx=true} true
```
