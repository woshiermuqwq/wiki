## 描述
检查目标的速度向量是否匹配给定参数。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| x         | s, side   | X 轴速度。可以是范围。如果未设置，条件不检查此项  |   |
| absx      | ax, abss, as | 是否仅使用 X 轴速度的绝对值        | `relative` 的值|
| y         | up, down, vertical, v | Y 轴速度。可以是范围。如果未设置，条件不检查此项 |   |
| absy      | ay        | 是否仅使用 Y 轴速度的绝对值           |  false  |
| z         | f, forward| Z 轴速度。可以是范围。如果未设置，条件不检查此项 |   |
| absz      | az, absf, af | 是否仅使用 Z 轴速度的绝对值        |  false  |
| relative  | rel | 检查是否应相对于实体的朝向而非世界坐标轴。如果为 true，X 为前/后，Z 为左/右                                     |  false  |

### X、Y 和 Z 属性
它们检查实体沿各坐标轴的速度。但这也意味着速度本身可以是正值或负值，具体取决于方向。 
> - 如果你正**朝着 `X 正值`方向移动**，你将具有**`正`的 X 速度**。
> - 如果你正**朝着 `X 负值`方向移动**，你将具有**`负`的 X 速度**。
> - 如果你正在**`向上`跳跃**，你将具有**`正`的 Y 速度**。
> - 如果你正在**`向下`坠落**，你将具有**`负`的 Y 速度**。

### Absx、Absy 和 Absz 属性
尽管有上述情况，你可能不想检查移动的*方向*，而是检查其*大小*。为此，你需要启用这些属性，启用后各自的 X、Y 或 Z 属性将仅检查绝对值（无论实际方向如何，均视为正值）。
> - 如果你正在**`向上`跳跃**，你将具有**`正`的 Y 速度**。
> - 如果你正在**`向下`坠落**，你将具有**`正`的 Y 速度**。


## 示例
在此示例中，我们检查玩家 Y 轴速度的绝对值是否小于 5。
```yaml
  Conditions:
  - directionalVelocity{y=<0;absx=true} true
```
