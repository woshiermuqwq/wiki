## 描述
检测目标实体的水平旋转角（yaw）是否在给定范围内。

## 属性

| 属性       | 别名   | 描述                               | 默认值 |
| ---------- | ------ | ---------------------------------- | ------ |
| yaw        | y      | 要检测的水平旋转角                   | 0      |
| clamp      | c      | 是否将角度钳制到 0-360 范围内        | true   |

## 示例
```yaml
  Conditions:
  - yaw{y=90to180} true
```

```yaml
  Conditions:
  - yaw{y=>0} true
```
