## 描述
检查目标实体的偏航角是否在范围内。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| yaw       | y         | 要检查的偏航角                                                 | 0       |
| clamp     | c         | 是否将偏航角限制在 0-360 范围内                     | true    |

## 示例
```yaml
  Conditions:
  - yaw{y=90to180} true
```

```yaml
  Conditions:
  - yaw{y=>0} true
```
