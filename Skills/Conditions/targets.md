## 描述
检测从父技能树继承的目标数量是否在给定范围内。

## 属性

| 属性       | 别名   | 描述                     | 默认值 |
| ---------- | ------ | ------------------------ | ------ |
| amount     | a      | 要检测的目标数量范围       | >0     |


## 示例
```yaml
  Conditions:
  - targets{a=>0} true
```

```yaml
  Conditions:
  - targets{a=0to5} true
```
