## 描述
检查从父级技能树继承的目标数量是否匹配给定范围。


## 属性

| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| amount    | a         | 要检查的目标数量范围                               | >0      |


## 示例
```yaml
  Conditions:
  - targets{a=>0} true
```

```yaml
  Conditions:
  - targets{a=0to5} true
```
