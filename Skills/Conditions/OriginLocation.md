## 描述
检查[起效点]是否在给定位置。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| location  | loc, l, c | 要匹配的位置，写作 `x,y,z`。                           |         |
| x         |           | 位置的 x 坐标，如果设置了 location 属性则忽略 | 0 |
| y         |           | 位置的 y 坐标，如果设置了 location 属性则忽略 | 0 | 
| z         |           | 位置的 z 坐标，如果设置了 location 属性则忽略 | 0 |
| exact     | e         | 是否精确匹配位置                                | false   |


## 示例
```yaml
  Conditions:
  - originLocation{loc=10,20,30} true
```
