## 描述
测试目标是否在施法者视线方向的给定角度范围内。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| angle     | a         | 要检查的视野角度                                     | 90      |
| rotation  | r         | 旋转要检查的视野                                          | 0       |


## 示例
```yaml
  TargetConditions:
  - fieldofview{angle=90} false
```
此条件将过滤掉所有在施法者 90 度视野内的目标。

##
```yaml
  TargetConditions:
  - fieldofview{angle=90} true
```
此条件将只允许在施法者 90 度视野内的实体被选中作为目标。
