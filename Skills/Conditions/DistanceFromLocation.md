## 描述
检测目标与指定位置之间的距离是否在某个范围内。

## 属性
| 属性       | 别名   | 描述                                       | 默认值 |
| ---------- | ------ | ------------------------------------------ | ------ |
| x          |        | 位置的 X 分量                               | 0      |
| y          |        | 位置的 Y 分量                               | 0      |
| z          |        | 位置的 Z 分量                               | 0      |
| world      | w      | 位置所在世界。默认为目标所在世界              |        |
| distance   | d      | 要与指定位置比较的距离                       |        |


## 示例
```yaml
  TargetConditions:
  - distanceFromLocation{x=10;y=20;z=30;distance=<20} true
```
