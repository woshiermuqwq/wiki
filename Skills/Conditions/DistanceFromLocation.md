## 描述
目标与指定位置之间的距离是否在范围内。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| x         |           | 位置的 x 分量                                      | 0       |
| y         |           | 位置的 y 分量                                      | 0       |
| z         |           | 位置的 z 分量                                      | 0       |
| world     | w         | 位置所在世界。默认为目标所在世界       |         |
| distance  | d         | 要检查的距指定位置的距离            |         |


## 示例
```yaml
  TargetConditions:
  - distanceFromLocation{x=10;y=20;z=30;distance=<20} true
```
