## 描述
检测施法者的碰撞箱是否与目标的重叠。

## 属性
| 属性          | 别名                              | 描述                           | 默认值 |
| ------------- | --------------------------------- | ------------------------------ | ------ |
| shiftforward  | so, forwardoffset, fo, forward, f | 施法者碰撞箱的前方偏移量         | 0.0    |


## 示例
```yaml
  TargetConditions:
  - boundingBoxesOverlap false
```


## 别名
- [x] bbsoverlap
