## 描述
Sets the leash holder of the caster to the targeted entity


## 属性
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| remove    | r, boolean, bool, b| If the lead 应当 removed instead of set                | false   |


## 示例
```yaml
  Skills:
  - setleashholder @NearestPlayer
```


## 别名
- [x] setleasher
