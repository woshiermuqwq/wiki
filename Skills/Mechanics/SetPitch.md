## 描述
Sets the head pitch of the target entity


## 属性
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| amount    | a, pitch, p | The value the pitch 将会 set to                                 | 0       |


## 示例
```yaml
  Skills:
  - setpitch{amount=45} @EIR{r=10}
```
