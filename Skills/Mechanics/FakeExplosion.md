## 描述
创建爆炸 effect 在specified target. Will play the sound and the particle effects, but won't cause any damage.


## 属性
> *This 机制 has no attributes*


## 示例
```yaml
ExplosionSkill:
  Skills:
  - fakeexplosion @self
```

## 别名
- [x] effect:explosion
- [x] e:explosion 
- [x] effect:explode 
- [x] e:explode 
- [x] fakeexplode
