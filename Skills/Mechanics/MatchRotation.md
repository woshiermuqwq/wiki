## 描述
Sets 施法者的 水平朝向(yaw) and 俯仰角(pitch) to the same value of 目标的


## 属性
| 属性 | 缩写   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| 目标    | to, t, location, loc, l, of | The [targeter](/Skills/Targeters)                  |<!--type:Targeter-->|


## 示例
```yaml
  Skills:
  - matchrotation @Parent
```


## 别名
- [x] matchrot
