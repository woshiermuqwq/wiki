## 描述
 
Causes a per-player storm effect (without rain) 


## 属性
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| level     | lvl, l, type, t, environment, env, e | The type of the effect. Either 0 or 1     | 0       |     


## Example
```yaml
Skills:
  - thunderlevel{l=1} @PIR{r=20} ~onSpawn
```


## 别名
- [x] effect:thunderlevel
- [x] e:thunderlevel
