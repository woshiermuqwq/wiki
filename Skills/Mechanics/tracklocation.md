## 描述
Sets the casting 生物's tracked location to 目标位置.  
Please note that a player cannot have a tracked location.  
This location can then be used via the relevant [Targeter](/Skills/Targeters/TrackedLocation) and [条件](/skills/条件/distancefromtrackedlocation).


## 属性
> *This 技能 has no attributes*


## 示例
```yaml
  Skills:
  - tracklocation @targetlocation
```

## 别名
- [x] settrackedlocation
- [x] stl
