## 描述
Sets the CustomModelData on the current 弹射物's bullet. (DISPLAY bullet types only)


## 属性
| 属性 | 缩写   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| value     |v, model, m| The model to set the 弹射物 to                                   | 0       |


## 示例
此示例将 set the 弹射物 bullet model number to 1234.
```yaml
  Skills:
  - setProjectileBulletModel{model=1234}
```
