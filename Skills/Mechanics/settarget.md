## 描述
Sets 生物的 目标 to the 目标 entity.
If using 仇恨 tables, will increase 仇恨 to the threshold to change 目标 for 目标实体.


## 属性
> *This 技能 has no attributes*


## 示例
Sets 施法者的 目标 to the 触发 when right clicked.
```yaml
  Skills:
  - setTarget @trigger ~onInteract
```


## 别名
- [x] 目标
