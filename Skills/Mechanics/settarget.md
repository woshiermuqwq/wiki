## 描述
Sets the mob's target to the target entity.
If using threat tables, will increase threat to the threshold to change targets 对于targeted entity.


## 属性
> *This 机制 has no attributes*


## 示例
Sets the caster's target to the trigger when right clicked.
```yaml
  Skills:
  - setTarget @trigger ~onInteract
```


## 别名
- [x] target
