# 数据类型

## 物品堆叠（ItemStack）
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| material | m | 物品堆叠粒子所基于的材料 | STONE |

## 方块数据（BlockData）
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| material | m | 方块数据粒子所基于的材料 | STONE |

## 材料数据（MaterialData）
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| material | m | 材料数据粒子所基于的材料 | STONE |

## 颜色（Color）
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| color | c | 粒子的颜色 | #FF0000 |

## 粉尘选项（DustOptions）
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| color | c | 粒子的颜色 | #FF0000 |
| size |  | 粒子的大小 | 1 |

## 粉尘过渡（DustTransition）
| 属性 | 缩写 | 描述 | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| color | c, color1, c1, fromcolor, fc | 粒子的起始颜色 | #FF0000 |
| color2 | c2, tocolor, tc | 粒子过渡到的颜色 | #0000FF |
| size |  | 粒子的大小 | 1 |
