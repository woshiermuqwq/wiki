## 描述
Instantly kills the 生物. This is a no-目标 技能 and will only
affect the casting 生物.  
This won't work on a few non-生物 entities like boats or armor stands! For them, the use of [Remove](/skills/技能/remove) is advised!

## 属性
> *This 技能 has no attributes*

## 示例
10% Chance to kill the casting 生物 when damaged.
```yaml
  Skills:
  - suicide ~onDamaged 0.1
```
