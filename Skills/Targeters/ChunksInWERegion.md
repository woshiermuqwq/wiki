## 描述
选取指定 WorldGuard 区域中各区块的 (0,0) 角落坐标


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| region    | r         | 区域名称                                               |         |


## 示例
```yaml
  Skills:
  - setchunkforceloaded @ChunksInWERegion{r=exampleregion}
```


## 别名
- [x] chunksInWGRegion
