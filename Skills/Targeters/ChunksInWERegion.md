## 描述
以0,0 chunk corners of the chunks in a specified WorldGuard 区域为目标。


## 属性
| 属性 | 别名 | Description | 默认 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| 区域 | r | The 名称 of the 区域 | |


## 示例
```yaml
  Skills:
  - setchunkforceloaded @ChunksInWERegion{r=exampleregion}
```


## 别名
- [x] chunksInWGRegion
