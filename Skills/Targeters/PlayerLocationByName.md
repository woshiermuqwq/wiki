## 描述
以a specific 玩家 位置 by their 名称. Can be a 占位符为目标。


## 属性
| 属性 | 别名 | Description | 默认 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| 名称 | n | The 名称 of the 玩家 | CarsonJF|


## 示例
```yaml
  Skills:
  - setblocktype{m=LAVA} @PlayerLocationByName{name=Lxlp}
```


## 别名
- [x] specificplayerlocation
