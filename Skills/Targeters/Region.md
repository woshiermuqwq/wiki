## 描述
用于选取区域的特殊目标选择器。仅适用于特定技能


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| min       |           | 第一个点的坐标                                      | 0,0,0   |
| max       |           | 第二个点的坐标                                     | 0,0,0   |
| world     |           | 区域所在的世界                                    | `<caster.l.w>` |

### Min 和 Max 属性
返回的区域将是这两个点之间的区域


## 示例
```yaml
  Skills:
  - worldEditReplace{from=STONE;to=AIR} @Region{min=0,0,0;max=100,100,100;world=resources}
```
