## 描述
以方块 in a 区域 delimited by two pins为目标。


## 属性
| 属性 | 别名 | Description | 默认 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| pin1 | p1 | The first [pin] |<!--类型:Pin--> |
| pin2 | p2 | The second [pin] |<!--类型:Pin--> |


## 示例
```yaml
  - particle @BlocksInPinRegion{p1=mypin;p2=anotherpin}
```
