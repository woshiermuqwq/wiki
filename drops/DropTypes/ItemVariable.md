## 描述
掉落指定物品变量中定义的物品


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| variable  | var, name, n | 要获取的物品变量的作用域和名称，格式为 scope.name | |


## 示例
```yaml
  Drops:
  - itemvariable{variable=caster.stolenitem} 1 1
```


## 别名
- [x] itemvar
