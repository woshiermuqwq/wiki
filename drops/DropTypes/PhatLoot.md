## 描述
从 `PhatLoot` 插件掉落一个物品。


## 属性
| 属性 | 别名   | 描述                                                          | 默认值 |
|-----------|-----------|----------------------------------------------------------------------|---------|
| type      | t         | 要掉落的对象                                                   |         |


## 示例
```yaml
  Drops:
  - phatloot LootTableName 1
```
```yaml
  Drops:
  - phatloot{t=LootTableName} 1
```
