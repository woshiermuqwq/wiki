## How To Set up 伪装
With the newer versions of MythicMobs, 伪装 can now be done 完全 内联 using the same **伪装 字符串** syntax as the in-game ``/disguise`` 指令.

For 示例, 让我们 say we want a skeleton 即 glowing, spinning, and on 触发. To get this 伪装 ingame, we would use the 指令: ``/disguise SKELETON setGlowing setSpinning setBurning``.
We can take this 指令, and use it on a 生物 紧挨 the 伪装 选项, like in the 示例 below:
```yml
SLSkelF:
  Type: ZOMBIE
  Equipment:

  - SHIELD OFFHAND
  - LEATHER_HELMET HEAD
  - LEATHER_CHESTPLATE CHEST

  - LEATHER_BOOTS FEET
  Display: '&BSkeletal Fighter\n&ELv.<mob.level>'
  Disguise: SKELETON setGlowing setSpinning setBurning
```

### Detailed steps

1. ``RumiIsAwesome`` would be the 名称 of your 伪装
2. ``player`` 意味着 它是 a 玩家 伪装
3. ``<inherit>`` means it will take its name from `显示:` 而不是 adding it here
4. ``setSkin RumiExMachina.png`` is telling it to set the 伪装 skin to your .png 文件 in the skins folder So if you have a skin named Goblin.png in the skins folder, use setSkin Goblin.png
5. ``setDynamicName`` 用于 allow the 伪装 名称 to change 经常, useful 当您 want to 显示 the 实体 血量 in its 名称


#### Nameplates

Nameplates allow you to extend the nameplates of 玩家-伪装 生物, 即 normally limited to 16 characters.
To use this, 仅仅 have Holograms installed and then leave 移除 “玩家” field in your 伪装 (skin is 仍然 必需!).
If you 不要 specify the 玩家 field, it将usethe 显示 field instead using a 自定义 nameplate。
Additionally, 生物 名称 can be put on multiple lines with diacritics (\n)
 

```yml
Monkey:
  Type: skeleton
  Display: "this display name is too \n long for players normally"
  Disguise: player Steve setSkin Kurdie.png
```
This feature 需要 LibsDisguises and the Holograms 插件: [https://www.spigotmc.org/resources/holograms.4924/](https://www.spigotmc.org/resources/holograms.4924/)

If you have LibsDisguises premium 您可以 use multi line 伪装 名称 using the `setDynamicName` 选项
